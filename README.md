# 待办小本：使用与自定义指南

这是一个本地 Windows 桌面待办工具。目前采用暖灰白、纸白和森林绿的界面，应用图标是一株嫩苗。左侧标题旁没有图片。

## 先看这三点

1. **更换图标需要重新生成程序。** 当前图标已嵌入 EXE，单独替换图片、重命名图片或修改快捷方式图标，都不会同时改变程序窗口和托盘图标。
2. **自定义不会要求清空待办。** 你的任务保存在 `data\tasks.xml`，生成脚本不修改这个文件。
3. **改之前备份整个文件夹最稳妥。** 脚本会在更新时备份旧 EXE 和图标，但不会自动备份你手动编辑之前的源代码。

## 一、平时怎么用

- 双击 `TodoNotebook.exe` 打开；输入事项，点击“添加待办”或按 Enter。
- “提醒”可选；可以指定时间，或选“10 分钟后”“今晚”“明天”。时间按电脑本地时间计算。
- “今天”显示截至今天到期的未完成事项，以及今天新建的无时间事项；“已完成”用于回看完成记录。
- “随手记”是独立的不提醒区域。这里的事项可以修改、完成和删除，但不会弹出提醒。
- 选中普通待办，点“移入随手记”，会取消它的提醒时间。当前没有对应的移回按钮；需要重新设置提醒时，可在“全部待办”中重新添加一条。
- 双击事项可编辑完整内容。长文字也可以悬停查看。
- 关闭主窗口只是收起到托盘。完全退出：右键电脑右下角的嫩苗图标，选择“退出程序”。图标可能藏在向上箭头内。
- 关闭提醒弹窗会延后 10 分钟；电脑关机或程序完全退出时不能提醒，重新启动后会检查错过的事项。
- “登录电脑时启动”可自行勾选。

## 二、最简单的换图标方法

### 准备图片

建议准备一张 **正方形、透明背景的 PNG**，尺寸约 512×512 或 1024×1024。主体居中、边缘留一点空间。简单的大形状在托盘里比细节复杂的照片更清楚。

透明 PNG 才能避免方形底色；转换脚本只是缩放和打包，**不会自动抠图**。把 JPG 改名成 PNG 也不会去掉背景。也可以直接使用制作好的 `.ico` 文件。

### 操作步骤

1. 先退出待办小本（右键托盘图标 → 退出程序）。
2. 把准备好的 PNG 放入 `assets` 文件夹，命名为 `custom.png`。注意不要变成 `custom.png.png`。
3. 打开 PowerShell，复制下面两行并执行：

```powershell
Set-Location -LiteralPath 'D:\project\待办小本'
& '.\重新生成.ps1'
```

4. 看到“更新完成”后，双击根目录中的 `TodoNotebook.exe`。

这会同时更新 **EXE 文件图标、窗口左上角图标、提醒与编辑窗口图标、系统托盘图标**，不会在侧栏重新添加图片。

脚本会生成 16、24、32、48、64、128、256 像素多个尺寸的图标，适配常见显示位置。过程无需联网；使用当前电脑已有的 .NET Framework 编译器。

### 不想改图片名字

可以指定文件路径（带空格或中文的路径都加引号）：

```powershell
& '.\重新生成.ps1' -IconPath 'D:\我的图片\新图标.png'
```

使用现成的 ICO：

```powershell
& '.\重新生成.ps1' -IconPath 'D:\我的图片\新图标.ico'
```

### 恢复嫩苗图标

```powershell
& '.\重新生成.ps1' -IconPath '.\assets\seedling.png'
```

如果不再需要自定义图片，把 `assets\custom.png` 改名或移走，避免下次普通生成时又使用它。

图标选择顺序：明确指定的 `-IconPath` → `assets\custom.png` → 当前的 `assets\app.ico`。

### 只生成，不替换正在用的程序

```powershell
& '.\重新生成.ps1' -BuildOnly
```

结果位于 `build\TodoNotebook.exe`。这个选项只检查能否生成和通过数据自检，不安装、不打开界面。不要把 build 目录当日常启动入口：程序的数据位置始终跟随 EXE 所在文件夹。

## 三、改配色

用文本编辑器打开 `source\Todo.cs`，搜索 `public static class Paper`。这里集中定义了主要颜色，修改引号中的十六进制色值即可：

| 名称 | 用途 | 当前色值 |
| --- | --- | --- |
| Background | 页面背景 | `#F5F4EF` |
| Surface | 卡片、弹窗背景 | `#FFFEFA` |
| Sidebar | 侧栏、次按钮背景 | `#EEF0E7` |
| Ink | 主文字 | `#203D35` |
| Accent | 主按钮、强调色 | `#27644F` |
| Muted | 辅助文字 | `#7A847B` |
| Border | 边框、分隔线 | `#E1E5DA` |
| Selected | 选中状态背景 | `#E3E9D9` |
| Warning / WarningText | 待办状态标签底色 / 文字 | `#F3EBD5` / `#725633` |
| Error / ErrorText | 错误底色 / 文字 | `#F3E2D9` / `#853E31` |

例如，将 `Accent` 的 `#27644F` 改成你喜欢的深绿色。保留 `#`、引号、逗号和分号，文件以 UTF-8 保存，然后退出程序，运行 `重新生成.ps1`。

建议一次只改一两种颜色，查看文字是否清晰。颜色太浅会影响阅读。

## 四、改字体、文字和布局

这些属于源代码自定义，目前没有“外观设置”页面。

| 想改什么 | 在 `source\Todo.cs` 搜索什么 | 注意 |
| --- | --- | --- |
| 窗口名称、侧栏标题、托盘提示 | `待办小本` | 有多处；只修改想更换的文字，不要改注册表键名或互斥锁标识 |
| 页面说明 | `把想做的事安放在这里` 等现有句子 | 修改双引号里的内容 |
| 字体 | `Microsoft YaHei UI` | 换成电脑已安装的字体 |
| 主窗口正文字号 | `10.5f` | 这里单位是点，不是像素；改大后需要检查按钮宽度 |
| 页面标题字号 | `Font.FontFamily,23` | 同样按点计算 |
| 卡片圆角、按钮圆角、桌面留白 | `Radius=12, ButtonRadius=8, Space=36` | 单位为布局像素 |
| 默认窗口尺寸 | `Size=new Size(1120,800)` | 宽、高 |
| 最小窗口尺寸 | `MinimumSize=new Size(760,640)` | 不建议直接降低，否则可能挤压操作区 |
| 完整 / 紧凑侧栏宽度 | `compact?136:220` | 默认紧凑 136、完整 220 |
| 紧凑布局切换点 | `ClientSize.Width<940` | 修改后要检查两侧临界尺寸 |

改完同样需要重新生成程序。界面使用 Windows 原生组件，日期选择器、文件选择对话框、窗口标题栏的部分外观由系统决定，不完全跟随配色。

目前侧栏没有头像控件。更换图标只影响图标，不会改变左侧布局。

## 五、备份、恢复和迁移

### 待办备份

- 在应用里点“导出备份”，保存 XML 文件。
- 或退出程序后，复制整个 `data` 文件夹。
- `data\tasks.xml.bak` 是上一次成功替换保存时留下的数据版本，不是长期历史记录；首次保存不一定有它。

### 恢复待办

1. 完全退出程序。
2. 把当前 `data` 文件夹另存一份。
3. 将导出的 XML 或 `tasks.xml.bak` 复制为 `data\tasks.xml`。
4. 重新打开程序。当前没有应用内“导入”按钮。

### 回退自定义程序

每次脚本成功安装更新前，会把旧程序和图标保存在 `backups\日期时间\` 中。

退出程序，把该备份里的 `TodoNotebook.exe` 复制回根目录；需要时同时把备份的 `app.ico` 复制回 `assets`。不要覆盖 `data`。源代码要用你自定义之前另存的版本恢复，否则下次重新生成仍会使用新代码。

根目录中 `TodoNotebook.before-paper.exe` 等是之前开发时留下的历史程序，不是日常启动入口。

### 移到别的文件夹

复制整个“待办小本”文件夹，包含 `data`。如果启用了登录启动，先在旧位置取消勾选，再在新位置启动程序并勾选一次，以更新启动路径。之后也要更新你自己的桌面快捷方式。

## 六、文件夹说明

```text
待办小本/
  TodoNotebook.exe        平时双击这个
  README.md               本指南
  重新生成.ps1            自定义后的生成与更新脚本
  assets/
    app.ico               最近安装的图标源文件
    seedling.png          嫩苗原图，透明背景
    custom.png            你可自行放入的图标图片（默认不存在）
  source/
    Todo.cs               界面与功能源代码
    IconPack.cs           图标多尺寸打包工具源码
  data/
    tasks.xml             当前待办
    tasks.xml.bak         上一版数据（存在时）
  build/                  运行脚本后产生的中间文件
  backups/                运行脚本安装更新后产生的程序备份
```

`assets` 里若还有旧头像图片，只是历史素材，当前程序不会读取或显示它。

## 七、遇到问题

**图片替换了，但图标没变**：必须重新生成程序并退出旧进程。若窗口和托盘已经更新、文件资源管理器仍显示旧图标，可能是系统图标缓存；先刷新文件夹或重新创建快捷方式，无需反复修改图片。

**提示程序仍在运行**：主窗口右上角关闭按钮只会收起。请右键托盘图标 → 退出程序，然后重新运行脚本。

**提示找不到编译器**：脚本依赖 Windows .NET Framework 编译器；这台电脑已经具备。迁移到另一台电脑时需单独确认，运行现成 EXE 和重新生成程序的要求不同。

**提示脚本被执行策略阻止**：先停止，不必为此修改整台电脑的安全设置。把完整提示交给我，我可以继续帮你生成程序。

**出现编译错误**：看错误中的行号，检查是否误删引号、逗号或括号。生成或自检失败时，脚本不会替换正在用的主程序。可以先恢复修改前的源文件，再重试。

**担心改坏**：先备份整个文件夹；用 `-BuildOnly` 验证，再在退出应用后正常生成安装。
